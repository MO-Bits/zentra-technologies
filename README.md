# Zentra Technologies

The official marketing website for Zentra Technologies Ltd—a Tanzanian
technology and engineering company building practical digital products,
automation systems and specialised innovations.

## Technology

- Next.js App Router
- React and TypeScript
- Tailwind CSS
- Vercel hosting

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production build

```bash
npm run build
npm run start
```

The production website is configured for `https://zentra.co.tz`.
